# Changelog

Every change to `@sagas/contracts` or `@sagas/fixtures` gets a line here, with
a contract version and a note on what a consumer has to do about it. Forks pin
to a tag; this file is how you decide whether pulling forward is worth it.

## v1.0.0 — unreleased

Initial contract.

  signals, translations.

  untranslated accounts, and coexisting renderings.
