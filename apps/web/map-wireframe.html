When the record is small
A place with one contributor still belongs on the map.

Call it a thin record and explain what would make it richer. Do not make it look empty, failed, or less worthy of visiting.

1Search and orientation

The search field is visible before the map. Later search can filter names and addresses, but the layout does not depend on a particular provider.

2Map and list together

The map helps someone orient themselves. The list contains the same places in words, so the experience works with no Mapbox token, for keyboard users, and for screen readers.

3Sparse records

A thin record is a real state of the archive. The interface invites more context without grading a contributor or implying that a place is unimportant.

Out of scope for this wireframe

Final pin art, address autocomplete, map-area loading, site creation, ranking, score display, and public deployment.
